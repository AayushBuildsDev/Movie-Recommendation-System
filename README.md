# Movie Recommendation System

A Flask-based Movie Recommendation System built using Python, Flask, MySQL, HTML, CSS, and the TMDB API.

## Features

- User Registration & Login
- Admin Dashboard
- Movie Search
- Genre Filter
- Movie Details
- TMDB Posters
- User Ratings
- Movie Recommendations

## Technologies Used

- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript
- TMDB API

## Installation

```bash
pip install -r requirements.txt
python app.py
